# Crochet Chart Maker — Free Crochet Graph Maker for Pixel Grids

[![Open the free tool](https://img.shields.io/badge/Open_the_free_tool-crochet--chart--maker.com-7B3F98?style=for-the-badge)](https://crochet-chart-maker.com/)

**[Crochet Chart Maker](https://crochet-chart-maker.com/)** turns a clear image—or a blank grid—into an editable color pixel graph in your browser. It is free, requires no account, and downloads a high-resolution PNG when the chart is ready.

> This tool creates color pixel grids, not traditional crochet stitch-symbol diagrams.

## What it does

- Converts JPG, PNG, and WebP images into limited-color crochet pixel grids.
- Supports blank grids from 10 × 10 to 150 × 150 cells.
- Offers Fit or Crop, grid-size controls, and palettes from 2 to 16 colors.
- Includes Pencil, Eraser, Fill, Picker, undo, redo, zoom, and palette editing.
- Exports a clean PNG with optional grid lines, row and column numbers, and a color legend.
- Processes the original image locally in the browser instead of uploading it for conversion.

## How it works

1. **Choose an image or blank grid.** Start with a simple, high-contrast image when possible.
2. **Set the grid and colors.** Pick the dimensions, Fit or Crop, and a practical palette size.
3. **Edit the graph.** Correct individual squares and adjust colors in the browser editor.
4. **Download the PNG.** Export a chart designed to remain readable away from the screen.

## Good fits

The tool is designed for color-grid projects such as graphghans, tapestry crochet, and other crochet work where one square represents a stitch or color block. It does not generate written row instructions, yarn estimates, PDF patterns, or traditional stitch symbols.

## FAQ

**Does my image get uploaded?**  
No. The source image is processed locally for chart generation. A compact grid draft may be stored in the browser, but the original image is not saved as part of that draft.

**Can I edit the generated result?**  
Yes. You can change individual cells, fill connected areas, sample colors, edit the palette, and undo or redo changes before exporting.

**Is it free?**  
Yes. The current tool is free to use and does not require an account.
