# Practical Browser Tools

I build focused browser-based tools that make one task easier to understand and complete.

## Height Comparer — Visual Height Comparison Tool

[![Open Height Comparer](https://img.shields.io/badge/Open_Height_Comparer-heightcomparer.com-1F6B4F?style=for-the-badge)](https://heightcomparer.com/)

**[Height Comparer](https://heightcomparer.com/)** turns numeric heights into proportional figures on one measured baseline. It works for quick two-person comparisons as well as larger lineups.

- Compare two or more people or characters on one chart.
- Switch between centimeters and feet plus inches.
- Edit names, measurements, silhouette styles, and colors.
- See the exact difference between the first two heights.
- Use the tool on mobile or desktop without creating an account.

### How it works

1. Enter a name and height for each subject.
2. Add more subjects or adjust their colors and silhouettes.
3. Read the lineup against the shared ruler and height-difference label.

The chart is a proportional visual reference based on the measurements entered; it does not verify real-world heights.

**[Compare heights visually](https://heightcomparer.com/)**

## Crochet Chart Maker — Crochet Graph Maker for Pixel Grids

[![Open the tool](https://img.shields.io/badge/Open_the_tool-crochet--chart--maker.com-7B3F98?style=for-the-badge)](https://crochet-chart-maker.com/)

**[Crochet Chart Maker](https://crochet-chart-maker.com/)** turns a clear image—or a blank grid—into an editable color pixel graph in your browser. It downloads a high-resolution PNG when the chart is ready.

> This tool creates color pixel grids, not traditional crochet stitch-symbol diagrams.

### What it does

- Converts JPG, PNG, and WebP images into limited-color crochet pixel grids.
- Supports blank grids from 10 × 10 to 150 × 150 cells.
- Offers Fit or Crop, grid-size controls, and palettes from 2 to 16 colors.
- Includes Pencil, Eraser, Fill, Picker, undo, redo, zoom, and palette editing.
- Exports a clean PNG with optional grid lines, row and column numbers, and a color legend.
- Processes the original image locally in the browser instead of uploading it for conversion.

### How it works

1. **Choose an image or blank grid.** Start with a simple, high-contrast image when possible.
2. **Set the grid and colors.** Pick the dimensions, Fit or Crop, and a practical palette size.
3. **Edit the graph.** Correct individual squares and adjust colors in the browser editor.
4. **Download the PNG.** Export a chart designed to remain readable away from the screen.

### Good fits

The tool is designed for color-grid projects such as graphghans, tapestry crochet, and other crochet work where one square represents a stitch or color block. It does not generate written row instructions, yarn estimates, PDF patterns, or traditional stitch symbols.

**[Open Crochet Chart Maker](https://crochet-chart-maker.com/)** and create an editable crochet pixel graph from an image or blank grid.
